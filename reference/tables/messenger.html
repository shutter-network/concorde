shared-agent-framework/messenger/schema ​

The tables this component creates, and the PostgreSQL schema saf_messenger it creates them in. A configuration listing shared-agent-framework/messenger/schema creates all of them.

Generated from the snapshot drizzle-kit takes of src/messenger/schema.ts, which is the snapshot an Operator's own generation reads. Never edited by hand.

Foreign keys leave this schema. messages.user_id points into saf_users, which shared-agent-framework/users/schema creates. A configuration that lists shared-agent-framework/messenger/schema without it generates a constraint onto a table nobody creates.
